# Report on the current state of Web Game Development in 2025 is published!

The results of the [Gamedev.js Survey 2025](https://gamedevjs.com/survey/2025/) are [published](https://gamedevjs.com/survey/report-on-the-current-state-of-web-game-development-in-2025-is-out/) already. Feel free to use the data from the [Report in PDF](https://gamedevjs.com/dl/gamedevjs-survey-2025-report.pdf) however you see fit, just remember to credit the source, thanks.

The next, [2026 edition](https://gamedevjs.com/survey/2026/) will be held in the second part of the year, around [js13kGames](https://js13kgames.com/) 2026. The questions are already here (`questions-2026.md`), so go ahead and make a [Pull Request](https://github.com/GamedevJS/Gamedev.js-Survey/pulls) if you think anything needs an update.

Don't forget about the upcoming [Gamedev.js Jam 2026](https://gamedevjs.com/jam/2026/) happening online April 13th-26th [on Itch](https://itch.io/jam/gamedevjs-2026), and subscribe to the [Gamedev.js Weekly](https://gamedevjsweekly.com/) newsletter if you haven't already.
